# Project WEEDY

**Home AI Companion Reference Project**

WEEDY is a concept-stage home AI companion reference project for M-PIN.

## WEEDY V1 Concept

![WEEDY V1 Concept](./weedy_v1_concept.png?v=2)

> Concept visualization — not a production device. Final hardware, modules, dimensions, and implementation may change.

## Modular Reference Direction

WEEDY is designed as a modular physical reference platform rather than a fixed robot product.

Concept modules may include:

- Camera / spatial-awareness module
- Tablet / display module
- Microphone module
- Speaker module
- Health-check contact module
- Mobility / battery module

The long-term direction is simple:

**Upgrade the capability without replacing the whole device.**

Hardware may change. Modules may change. The M-PIN principle remains.
